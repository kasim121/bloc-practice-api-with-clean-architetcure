# Dart basics

This folder contains small, standalone Dart examples for learning the language
used by this Flutter project. Each file has a short definition and a `main`
function that demonstrates the idea. Run an example from the project root with
`dart run lib/basic/<file_name>.dart`.

## Topics

- `variables.dart` — declaring and updating values
- `data_types.dart` — common Dart types
- `operators.dart` — arithmetic, comparison, and logical operators
- `control_flow.dart` — conditions and loops
- `functions.dart` — reusable operations and return values
- `collections.dart` — lists, sets, and maps
- `null_safety.dart` — nullable values and safe access
- `classes.dart` — classes, objects, and constructors
- `async_basics.dart` — asynchronous work with `Future` and `async`/`await`
